## Blue Team / SOC
- [LetsDefend](https://letsdefend.io) — SOC alert triage and incident investigation simulations
- [Wazuh Documentation](https://documentation.wazuh.com) — open-source SIEM/XDR used in the [Build & Breach lab](/projects/)

## Offensive Security / CTFs
- [TryHackMe](https://tryhackme.com) — guided, hands-on rooms covering offensive and defensive security
- [Hack The Box](https://www.hackthebox.com) — vulnerable machines and CTF-style challenges
- [PortSwigger Web Security Academy](https://portswigger.net/web-security) — free, in-depth web application security training

## Foundations & Certifications
- [Google Cybersecurity Certificate](https://www.coursera.org/professional-certificates/google-cybersecurity) — foundational SOC, network, and Linux/SQL skills (see [Certifications](/certs/))
- [MITRE ATT&CK](https://attack.mitre.org) — adversary tactics and techniques knowledge base, referenced when triaging alerts and writing up investigations
- [NIST Cybersecurity Framework](https://www.nist.gov/cyberframework) — risk management and security program structure
